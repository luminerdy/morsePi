## Sources of Truth

- Requirements and acceptance criteria: `specs/`, with stable requirement IDs.
- What is implemented or still partial: [spec status](../specs/STATUS.md).
- Prioritized future work: [product roadmap](product/ROADMAP.md).
- Delivered changes: [changelog](../CHANGELOG.md).
- How to operate a station: the guides above.
- Daily evidence and past discussion: [project log](PROJECT_PLAN.md), not a
  second roadmap. Older dated entries can describe superseded behavior.

Do not include credentials, live student progress, or identifiable family
screenshots in new documentation examples. Use fictional students and networks.
Existing assets require a separate privacy review before reusing them publicly.
