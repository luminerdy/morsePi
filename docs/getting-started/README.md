# Build a Station

1. Choose [parts and budget options](../BILL_OF_MATERIALS.md).
2. Check [display and case fit](../CASE_MEASUREMENT_WORKSHEET.md).
3. Follow [fresh Pi setup and configuration](../SETUP_AND_CONFIGURE_PI.md),
   including wiring, services, audio, and administration.
4. Run the [station deployment checklist](../GRANDKID_STATION_DEPLOYMENT.md).
   Its historical family wording applies to any household installation.
5. At the destination, use the [touchscreen Wi-Fi checklist](../HOME_WIFI_SETUP_CHECKLIST.md).
6. Give the family the [student guide](../user-guide/README.md).

Start with a working standalone station. Add [AWS services](../AWS_SETUP_REFERENCE.md)
only when backup uploads, inter-station sync/messages, or remote updates are needed.
Use your own account, station IDs, student identities, and credentials; never copy
a deployed family's configuration.

Fresh-SD install and recovery verification remain explicit release-readiness
work on the [roadmap](../product/ROADMAP.md).
